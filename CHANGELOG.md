# История версий

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). Английская версия описаний — в текстах релизов на GitHub.

## [1.3.0] — 2026-09-28

### Изменено
- Одно окно **«Настройки»** вместо двух: схема клавиш с панелью настройки стала главным окном, прежняя таблица удалена.
- В шапку окна перенесены «Перехват клавиш», «Тема», «Автозагрузка» и «Режим администратора» (они же остались в меню трея); внизу — строка состояния, «О программе», «Свернуть в трей».
- Окно растягивается; при нехватке места появляется прокрутка, нижняя строка остаётся на месте.
- Клавиши на схеме стали на ~30% меньше.
- Подписи на клавишах: название программы из её exe, у сайта — только адрес (без `https://`, `www.` и пути), у папки — её имя. Длинные подписи переносятся на вторую строку.
- Значок «есть действия в программе» перенесён в правый верхний угол клавиши.
- На втором уровне подсказка «что клавиша делает без мастер-клавиши» перенесена с клавиш в панель справа.
- Для новых программ «Если уже открыто» по умолчанию — «Переключиться».

### Исправлено
- Память возвращается системе через несколько секунд после любой активности (запуск, сочетание, меню трея), а не только после закрытия окна настроек.
- Понятное сообщение, если в поле «Программа» указана папка.
- Приватный Firefox подписан «Firefox · приватный».

## [1.2.0] — 2026-09-27

### Добавлено
- **Карта клавиш**: схема цифрового блока или встроенного блока ноутбука с панелью настройки выбранной клавиши.
- Два уровня на карте: «Основные клавиши» и «Клавиши в программе · название».
- Сохранение кнопкой «Сохранить» с вопросом при переходе к другой клавише и закрытии.

### Исправлено
- Падение при любом изменении на карте.

## [1.1.1] — 2026-09-26

### Добавлено
- Действия набора программы трёх типов: сочетание, сайт (в этом же браузере), файл (в этой же программе).
- Окно выбора «с удержанием мастер-клавиши / без удержания» при включении набора.
- Приватные окна Firefox настраиваются отдельно от обычных.
- Журнал отладки в меню трея.

### Изменено
- Одну программу можно назначить только на одну клавишу.
- Режим администратора доступен только при установке в Program Files (защита от повышения прав).
- Окно настроек уничтожается при сворачивании в трей — меньше памяти в фоне.

### Исправлено
- Удержание Num 0: клавиши не из набора больше не запускают основное действие.
- Залипание модификаторов после экрана блокировки.
- Сайт из набора открывается новой вкладкой в активном окне браузера.
- Вторая копия программы не запускается, если первая работает от имени администратора.

## [1.0.2] — 2026-09-26

### Добавлено
- Название **Numpad Launcher Pro**.
- Панель «Настройки» у каждой клавиши: показываются только поля выбранного типа, значения других типов сохраняются.
- Тип действия «Открыть папку».
- Мастер-клавиша для набора программы: Ctrl, Alt, Shift или удержание Num 0.
- Возможности программ: окно, от имени администратора, «переключиться / свернуть», «перебирать окна»; у сайта — свой браузер и приватное окно; у команды — скрытая консоль.

### Изменено
- Лицензия: бесплатно для личного использования, коммерческое — по лицензии.

## [1.0.1] — 2026-09-25

### Добавлено
- Все 16 клавиш цифрового блока, перехват только при включённом NumLock.
- Типы действий «Выполнить» и «Сочетание клавиш» с окном записи сочетания.
- «Если уже открыто»: открыть ещё или переключиться; для сайтов — вкладка или окно.
- Наборы сочетаний для отдельных программ.
- Вывод запущенной программы на передний план.
- Режим администратора через Планировщик заданий.
- Русский и английский язык, лицензионное соглашение.

## [1.0] — 2026-09-25

- Первая версия: запуск программ и сайтов клавишами Num 0–9, значок в трее, светлая и тёмная тема, автозагрузка, установщик.
